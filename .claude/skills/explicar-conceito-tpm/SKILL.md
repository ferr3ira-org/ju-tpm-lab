# Skill: explicar-conceito-tpm

Use esta skill para explicar um conceito técnico para uma TPM iniciante.

## Formato de resposta

1. Explicação simples
2. Analogia
3. Exemplo prático
4. Como isso aparece em times de tecnologia
5. Pergunta para validar entendimento

## Tom

- Simples
- Sem jargão desnecessário
- Com exemplos concretos
