# Backlog — Glossário Tech para TPM

## Alta prioridade (MVP)

- Como TPM, eu quero cadastrar um novo termo (com categoria, explicação simples e exemplo), para que eu possa estudá-lo depois.
- Como TPM, eu quero listar os termos cadastrados e ver a categoria de cada um, para que eu saiba a qual assunto cada termo pertence.
- Como TPM, eu quero editar um termo existente, para que eu possa corrigir caso alguma informação não esteja correta.
- Como TPM, eu quero remover um termo, para que eu possa excluir algo que não faça mais sentido manter.
- Como TPM, eu quero marcar o status de um termo como "estudando" ou "entendido", para que eu saiba se ainda preciso aprofundar ou se já domino aquele conceito.

## Baixa prioridade / futuro

- Como TPM, eu quero ter login de usuário, para que meus dados fiquem protegidos caso mais pessoas passem a usar o glossário no futuro. Não é prioridade agora porque a única usuária sou eu.
- Como TPM, eu quero suportar múltiplos usuários, para que mais pessoas possam atuar no glossário ao mesmo tempo. Não é prioridade agora porque não há essa necessidade no momento.
- Como TPM, eu quero uma busca avançada, para que eu consiga encontrar termos com mais facilidade caso o glossário cresça e fique mais robusto. Não é obrigatório agora, mas pode ser interessante numa atualização futura.
- Como TPM, eu quero anexar arquivos aos termos (como prints e imagens), para que eu tenha informações complementares às explicações e exemplos. Ainda não é possível nesta versão.
