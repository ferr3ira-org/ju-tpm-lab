# Desafio 05 — Front básico

## Objetivo

Criar uma interface simples para consumir a API REST em Go.

## Funcionalidades mínimas

- Listar termos
- Criar termo
- Editar termo
- Remover termo
- Marcar termo como entendido

## Estrutura sugerida

```text
produto-final/frontend/
  README.md
  index.html
  src/
```

Pode ser React, Vite ou HTML/JS simples. A escolha deve ser documentada em `docs/decisoes.md`.

## Entregáveis

```text
produto-final/frontend/
desafios/05-front/output/explicacao-front.md
desafios/05-front/output/prints-ou-descricao.md
```

## Critérios de aceite

- [ ] Front roda localmente.
- [ ] Consome a API.
- [ ] Tem README com instruções.
- [ ] Ju consegue explicar diferença entre front e backend.
