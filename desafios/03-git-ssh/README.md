# Desafio 03 — Git, SSH, branch e Pull Request

## Objetivo

Aprender o fluxo básico de trabalho com GitHub:

```text
branch → commit → push → Pull Request → review → merge
```

## Conceitos

Explique com suas palavras:

- Git
- GitHub
- repositório
- clone
- branch
- commit
- push
- Pull Request
- review
- merge
- chave SSH

## Passos

1. Ler `COMO-ABRIR-PR.md`.
2. Configurar chave SSH, se necessário.
3. Criar uma branch para este desafio.
4. Criar os arquivos de output.
5. Abrir PR.
6. Solicitar review do Doug.
7. Corrigir feedback se houver.
8. Mergear só após aprovação.
