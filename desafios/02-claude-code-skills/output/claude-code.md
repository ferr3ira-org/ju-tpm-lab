# O que é Claude Code

## Explicação simples

Claude Code é um programa que uso no terminal para conversar com a IA (Claude) enquanto ela mexe direto nos arquivos do meu computador — lê, cria, edita, roda comandos de git, etc. Não é um chat qualquer: é um assistente que trabalha dentro do meu projeto real, não só fala sobre ele.

## Minha analogia

O Claude Code é como um psicólogo diferente: ele te dá conselhos e ajuda, mas também consegue entrar na sua cabeça (o sistema) e mudar de verdade um estado — tipo a ansiedade — não só falar sobre isso. Só que antes de mexer em algo importante, ele pergunta se pode e espera sua autorização.

## Exemplo prático

Foi o que fiz nos desafios 01 e 02 do meu trail: abri o terminal na pasta `~/estudos`, rodei `claude --add-dir ./ju-tpm-lab`, e a partir daí pedi pra ele ler o README, me explicar conceitos, e só quando eu mandava, criar arquivos como este, dentro do repo.

## Como isso aparece em times de tecnologia

Devs usam ferramentas assim para acelerar tarefas repetitivas: escrever testes, revisar PRs, documentar código, investigar bugs. O time ganha velocidade, mas continua responsável por revisar o que a IA fez antes de aceitar — foi exatamente essa regra que segui neste desafio, revisando cada trecho antes de pedir para criar o arquivo.

## O que ficou confuso no começo

No início, achei que Claude Code fosse só mais um chat de IA, tipo o ChatGPT, que só me dá um texto pronto pra eu copiar e colar. Eu tinha esquecido que ele pode de fato mexer nos arquivos e pastas do meu computador — ele tem acesso a praticamente tudo. Ele realmente faz coisas por mim, mas sempre com o meu aval antes.
