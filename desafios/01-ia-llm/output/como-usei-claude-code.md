# Como usei o Claude Code — Desafio 01

## Prompts que usei

- "Seguir com o desafio atual" — pedi para o Claude Code identificar em que desafio eu estava e continuar a partir dali.
- Pedi para o Claude Code explicar os conceitos do desafio (IA generativa, LLM, prompt, contexto, alucinação, eval, por que não confiar cegamente na IA) antes de escrever qualquer arquivo.
- Fui mandando meu resumo próprio, conceito por conceito, e pedindo feedback sobre o que estava bom e o que podia melhorar.
- Mandei cada par de prompt bom/ruim que criei e pedi pra ele explicar por que o prompt ruim era vago e me ajudar a entender o que faltava, antes de eu escrever a versão melhorada.
- Pedi ajuda para organizar minha reflexão final em formato de arquivo.

## O que a IA ajudou a entender

- A diferença entre um prompt vago e um prompt bem construído: ela apontou um padrão em quase todos os meus prompts ruins — falta de contexto (quem está perguntando) e falta de recorte (o que exatamente eu queria saber).
- Como organizar texto solto em markdown com títulos, sem mudar o sentido do que eu escrevi.

## O que revisei antes de aceitar

- Li todas as explicações de conceitos e só considerei "entendido" depois de reescrever cada um com minhas próprias palavras — não copiei a explicação da IA direto para o resumo.
- Conferi se os resumos organizados em markdown mantinham exatamente o que eu quis dizer, sem a IA acrescentar informação nova que eu não tinha escrito.
- Antes de qualquer arquivo ser criado, pedi para ver o conteúdo primeiro e só autorizei a criação depois de revisar.
