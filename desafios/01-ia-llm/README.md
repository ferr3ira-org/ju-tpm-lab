# Desafio 01 — IA e LLM básico

## Objetivo

Entender conceitos básicos de IA para usar Claude Code e outros assistentes com mais segurança.

## Conceitos

Você precisa explicar com suas palavras:

- O que é IA generativa
- O que é LLM
- O que é prompt
- O que é contexto
- O que é alucinação
- O que é eval
- Por que não devemos confiar cegamente na IA

## Passos

1. Use Claude/ChatGPT para pedir explicações simples.
2. Escreva seu próprio resumo.
3. Crie 5 exemplos de bons prompts.
4. Crie 5 exemplos de prompts ruins e depois melhore cada um.
5. Escreva uma reflexão: “como uma TPM pode usar IA no dia a dia?”.
