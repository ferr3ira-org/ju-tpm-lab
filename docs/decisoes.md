## Decisão: Tecnologia do front-end do Desafio 05

- Data: 2026-08-13
- Contexto: Preciso construir uma interface simples para consumir a API REST em Go (desafio 04), com as funcionalidades de listar, criar, editar, remover e marcar termo como entendido. Sou iniciante em programação e o objetivo do desafio é aprender o conceito de front-end, não me tornar desenvolvedora.
- Opções consideradas:
  - HTML/JS simples (sem frameworks, roda direto no navegador).
  - React (biblioteca popular no mercado, organiza a interface em componentes).
  - React + Vite (React com uma ferramenta de build mais rápida).
- Decisão: HTML/JS simples, com arquivos separados (`index.html`, `app.js`, `style.css`).
- Por quê: é a opção mais fácil de entender nesse primeiro momento — não exige instalar ferramentas extras, e dá pra ver exatamente o que cada linha de código está fazendo. React fica pra uma etapa futura, quando eu já tiver mais familiaridade com os conceitos básicos de front-end.
