# Prompts úteis

## Explicar conceito

```text
Explique [conceito] para uma TPM iniciante, com analogia simples e exemplo prático.
```

## Quebrar tarefa

```text
Quebre essa tarefa em passos pequenos. Não faça por mim; me guie e explique cada passo.
```

## Revisar entendimento

```text
Revise minha explicação abaixo. Aponte o que está correto, o que está confuso e o que falta.
```
