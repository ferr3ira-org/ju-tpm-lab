# Produto — Glossário Tech para TPM

Durante toda a trilha será desenvolvido um único produto: **Glossário Tech para TPM**.

A escolha do produto já está feita para evitar que você precise decidir uma aplicação do zero. Assim, você pode focar no aprendizado técnico e no fluxo de trabalho.

## O que é o produto?

Uma aplicação simples para cadastrar e consultar termos técnicos usados no dia a dia de tecnologia.

Exemplos de termos:

- API
- Docker
- Pull Request
- Endpoint
- Deploy
- Incidente
- SLA

## Campos de cada termo

| Campo | Exemplo | Explicação |
|---|---|---|
| `termo` | `API` | Nome do conceito técnico. |
| `categoria` | `Backend` | Grupo do termo. |
| `explicacao_simples` | `Uma forma de sistemas conversarem.` | Explicação em linguagem simples. |
| `exemplo` | `Um app consulta uma API de clima.` | Exemplo prático. |
| `status` | `estudando` | Pode ser `estudando` ou `entendido`. |

## O que o produto terá no final?

- API REST em Go.
- Front-end simples.
- Docker Compose.

## Por que esse produto é útil para uma TPM?

Porque ajuda a praticar tecnologia com um produto pequeno, fácil de entender e conectado ao dia a dia de produto e engenharia.
